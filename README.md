## Flag Format

All flags follow the format:

```text
NSC{...}
```

Some challenges use a local `flag.txt` placeholder, while others generate flags dynamically when the environment starts.

## Running a Challenge

Most networked challenges include their own infrastructure. Refer to the challenge directory for the exact setup instructions.


## Archive Notes

This repository is intended to preserve the challenges, supporting files, and writeups from NorthSec CTF 2026 in a single place.

Some challenges do not include a writeup, either because none was published or because the corresponding solution is not currently available in the repository.
