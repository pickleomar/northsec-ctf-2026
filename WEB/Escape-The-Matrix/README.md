# Escape The Matrix

## Category: WEB

## Author: pickleomar

### Description

There is a matrix and it should be escaped 

## Setup

Build and start the challenge:

docker build -t escape-the-matrix .

# Run the container
docker run -p 8080:8080 escape-the-matrix escape-matrix-diagonalhh

The challenge will be available at:

```text
http://localhost:8080
```
